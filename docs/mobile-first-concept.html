Design Decisions · Phase 1 Scope

Bottom tab bar замість RightNavbar

На мобілі RightNavbar з min-w-[260px] зникає. Desktop зберігає sidebar через md: breakpoint.

FAB для primary action

"+" у thumb zone. Passes / Issues мають FAB; Dashboard / News / Profile — ні.

44×44 touch targets

Усі інтерактивні елементи мають .tap class. WCAG 2.5.5.

Уніфіковані токени

Тільки primary.*, saas.*, success/warning/danger. nordic.* — deprecated.

Safe-area inset

Tab bar має padding-bottom: env(safe-area-inset-bottom) для iPhone notch.

Role-aware shell

Tenant бачить 5 tabs. Guard / Dispatcher — інший набір (буде в Phase 2). Admin залишається desktop-only.
